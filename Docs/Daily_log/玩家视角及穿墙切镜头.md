## 问题总结：第三人称摄像机仰视时穿模

### 现象
- 鼠标上推（仰视）时，摄像机会从角色下方往上拍，看到裙底。
- 小腿穿模，视觉上角色像悬空。
- 改 `minPitch` 参数**没有效果**。

---

## 根本原因（两层）

### 原因 1：角度限制 ≠ 高度限制
只靠 `minPitch` 无法解决，因为摄像机位置公式是：

```
摄像机 y = 角色 y + targetOffset.y + sin(pitch) * distance
```

举例：`targetOffset.y = 1.4`，`distance = 5`，`minPitch = -20°`

```
sin(-20°) * 5 = -1.71
摄像机 y = 角色 y + 1.4 - 1.71 = 角色 y - 0.31
```

**摄像机还是跑到脚底下方。** 距离越远，角度对高度的影响越大。所以光限制角度不够，必须额外限制最低高度。

### 原因 2：Unity 序列化坑 —— 脚本换了，Inspector 不刷新
你替换了脚本，但 Inspector 里显示的仍是旧值：
- `Max Pitch = 80`（脚本新默认是 60）
- `Min Pitch = -80`（脚本新默认是 -20）
- `Target Offset = 1.2`（脚本新默认是 1.4）

Unity 的 `[SerializeField]` 特性：**一旦 Inspector 保存过值，就会用保存的值，不会用脚本里的新默认值。** 这就是"改脚本没用"的真相。

### 原因 3（隐藏的）：脚本可能没真正替换
替换脚本后，如果 Unity 编译成功但 Inspector 里**连字段都没出现**（比如没有 `Min Camera Height`），说明打开的文件不是最新版本，或者保存没生效。

---

## 解决方案

### 修复 1：加 `minCameraHeight` 强制下限
在摄像机位置算完后，硬性限制 y 坐标：

```csharp
Vector3 finalPosition = pivot + offsetDir * actualDistance;

// 关键：强制最低高度
float minY = target.position.y + minCameraHeight;
if (finalPosition.y < minY)
{
    finalPosition.y = minY;
}
```

`minCameraHeight = 0.5` 表示摄像机永远不会低于角色脚底上方 0.5 米。**无论 pitch 和 distance 怎么变，都不穿模。**

### 修复 2：正确替换脚本后的刷新流程
替换脚本后必须做：
1. **保存脚本** `Ctrl + S`，等编译完成。
2. **选中 Main Camera**，右键 `ThirdPersonCamera` 组件标题栏 → `Reset`，强制刷新为脚本新默认值。
3. Reset 后 `Target`、`Collision Mask` 会被清空，**手动重新指定**：
   - `Target` 拖入场景里的 Player。
   - `Collision Mask` 取消勾选 Player Layer。
4. **确认 Inspector 里有 `Min Camera Height` 字段** —— 有这个字段才说明脚本真的换了。

### 修复 3：把 Player 单独一个 Layer
- `User Layer 8` 命名 `Player`。
- 场景里 Player 根节点 Layer 改成 `Player`，右键"Change children too"。
- `Collision Mask` 里取消勾选 `Player`。
- 目的：SphereCast 不撞到自己，摄像机不会被推近贴脸。

---

## 最终参数

| 参数 | 值 | 作用 |
| :--- | :--- | :--- |
| `Target Offset` | `(0, 1.4, 0)` | 注视点在头肩，抬高视线中心 |
| `Max Pitch` | `60` | 俯视上限 |
| `Min Pitch` | `-30` | 仰视上限 |
| `Min Camera Height` | `0.5` | 摄像机最低高度硬限制 |
| `Min Distance` | `1.2` | 被障碍物推近时的最近距离 |
| `Collision Radius` | `0.25` | SphereCast 半径 |
| `Collision Mask` | Player 不勾 | 避免打到自己 |

## 面试时可以这样讲

> "第三人称摄像机我用的是球体射线碰撞检测（SphereCast），从角色头肩位置向摄像机方向发射，检测到障碍物就把摄像机拉近，避免穿墙。同时加了两个约束：一个是 pitch 角度限制，另一个是**最低高度硬限制**——因为光靠角度限制不足以防止摄像机跑到脚底，当距离乘 sin(pitch) 大于注视点偏移时，摄像机还是会钻到角色下方。这是大部分第三人称游戏都会遇到的边界问题。另外我把 Player 单独分了一个 Layer 并从碰撞检测里排除，避免摄像机打到角色自己的 CharacterController 导致贴脸。"

---

## 你在这次问题里学到的三个通用技巧

1. **角度限制 ≠ 高度限制**：涉及摄像机位置时，要同时约束角度和空间坐标。
2. **Unity 序列化不刷新**：改脚本默认值后，必须 Reset 组件或手动改 Inspector 值，否则旧值一直生效。
3. **Layer 隔离**：摄像机碰撞检测要排除角色自己所在的层，否则会被自己的碰撞体干扰。
