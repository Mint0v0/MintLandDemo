## 问题现象

- 攻击动画播完后，切回 `Idle` 时，**角色会"平移"或"弹回"到攻击开始前的位置**。
- 攻击动画本身 `Average Velocity = (0, 0, 0)`，`Curves` 也是空的。
- 攻击期间按 WASD，角色会一边挥刀一边漂移。

---

## 根本原因

1. **攻击动画里"身体骨骼（Hips/Pelvis）"有局部位移**  
   动画设计师为了让攻击有"前冲感"，把位移烘进了骨盆骨骼的姿势里。虽然根节点（Root）没动，但骨盆视觉上向前移动了。
   
2. **切回 Idle 时骨盆要归位**  
   Idle 动画的第一帧，骨盆在原点。攻击结束切回 Idle 时，骨盆从"前冲位置"回到"原点"，视觉上就是**弹回**。

3. **`Apply Root Motion` 关着，代码又不管这个偏移**  
   你的架构是"代码驱动移动 + 动画只做表现"。`PlayerController` 用 `CharacterController.Move` 控制根节点，完全无视动画里的骨盆位移。所以骨盆怎么动，根节点都不管，切回 Idle 就露馅了。

4. **攻击期间没有锁定移动**  
   `PlayerController.HandleMovement` 没有判断攻击状态，按 WASD 照样推角色，和攻击动画打架，看起来就是漂。

---

## 解决方案

### 第一层：表现层通知逻辑层锁定输入

在 `PlayerController` 里加一个攻击状态开关：

```csharp
private bool _isAttacking;
public bool IsAttacking => _isAttacking;
public void SetAttacking(bool attacking) { _isAttacking = attacking; }
```

并在 `HandleMovement()` 和 `RotatePlayer()` 开头加：

```csharp
if (_isAttacking) return;
```

**架构意义**：表现层通过 `SetAttacking` 通知逻辑层，逻辑层决定"锁不锁"。这是**逻辑驱动表现，表现反馈逻辑**的双向通信，没有破坏原有的分层。

---

### 第二层：攻击状态识别

在 `PlayerAnimationBridge` 里，每帧从 Animator 读取当前状态：

```csharp
bool isInAttackState = state.IsTag("Attack") 
                    || state.IsName("Attack1") 
                    || state.IsName("Attack2");
```

**关键点**：给 Animator 里的 `Attack1`、`Attack2` 状态都打上 `Attack` Tag。  
用 Tag 判断比 IsName 更稳，尤其在有连击、过渡、子状态机时。

---

### 第三层：LateUpdate 里的"骨盆世界坐标锁定"

这是最核心、最精彩的一步。

**攻击期间**：
```csharp
if (isInAttackState && _bodyBone != null)
{
    // 每帧记录骨盆当前世界坐标
    _lockedHipsWorldPos = _bodyBone.position;
}
```

**攻击结束那一帧**：
```csharp
else if (_wasInAttackState && _bodyBone != null)
{
    // 冻结锁定值为攻击最后一帧的骨盆世界坐标
    // 启动追踪计时器（比如 0.6 秒，覆盖过渡期）
    _attackExitTrackingTimer = attackExitTrackingDuration;
}
```

**LateUpdate 里每帧补偿**：
```csharp
private void LateUpdate()
{
    if (_attackExitTrackingTimer > 0f && _bodyBone != null)
    {
        Vector3 delta = _lockedHipsWorldPos - _bodyBone.position;
        delta.y = 0f;
        if (delta.magnitude > 0.0001f)
            _characterController.Move(delta);  // 把根节点移过去补差
    }
}
```

**原理**：
- Animator 在 `Update` 阶段更新骨骼姿势，`LateUpdate` 里骨骼已经是最新的。
- 攻击结束切回 Idle 时，骨盆会从"前冲位置"往"原点"走。
- 我们在 `LateUpdate` 里每帧计算"骨盆应该在哪（锁定值）"和"骨盆现在在哪"的差值，然后用 `CharacterController.Move` 把根节点往差的方向推。
- 结果：**骨盆的世界坐标被锁死不变，根节点跟着骨盆的"回位"往前补**，视觉上角色就停在原地，不弹回。

---

### 第四层：参数调优

- `attackExitTrackingDuration = 0.6f`  
  必须**大于等于** `Attack -> Idle` 的 `Transition Duration`，否则过渡还没完成追踪就断了。
- `Attack1 -> Idle` 和 `Attack2 -> Idle` 两个过渡必须设置一致：
  - `Has Exit Time`：✅
  - `Exit Time`：`0.9`
  - `Transition Duration`：`0.15` ~ `0.2`

---

## 总结成一句话

> **用"攻击期间每帧记录骨盆世界坐标 + 攻击结束后在 LateUpdate 里持续补偿根节点"的方式，把动画里的骨盆位移'转嫁'到根节点上，实现攻击原地化且不弹回。**

>
> "这套方案的本质是**表现层通过 `LateUpdate` 主动补偿根节点，让动画位移和代码位移在视觉上达成一致**。比直接开 `Apply Root Motion` 更可控，因为根运动会和 `CharacterController` 打架，而补偿法只在过渡期做，不影响正常移动。"
